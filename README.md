# Portfolio

Site personnel de Pauline Peeters, développeuse web full-stack.

HTML et CSS statiques, sans build : ouvrir `index.html` dans un navigateur suffit.

## Mise en ligne avec GitHub Pages

1. Créer le dépôt public `PaulinePeeters.github.io` sur GitHub.
2. Pousser ce dossier sur la branche `main`.
3. Le site est servi sur https://paulinepeeters.github.io
