Projets choisis

RestOS

Logiciel de gestion de restaurant, mon travail de fin d’études

Un seul outil pour tout le restaurant : la salle prend les commandes sur un plan de tables interactif, la cuisine les voit arriver en direct sur son écran, et le gérant suit les stocks, le personnel et les ventes.

  • Commandes synchronisées en temps réel entre salle et cuisine (Socket.IO)
  • Plan de salle éditable dessiné sur canvas (React Konva)
  • Rôles et permissions, plannings, absences, pointage
  • Stocks, allergènes, factures PDF, QR codes, tableaux de bord
  • API testée et documentée avec une collection Postman complète

React 19, TypeScript, Node.js, Express, PostgreSQL, Prisma, Zod, JWT, Docker

ArtStock

Gestion d’inventaire, en production

Une application qui remplace les tableurs : inventaire des œuvres et du matériel, calendrier, exports PDF. Je l’ai migrée d’un hébergement Render vers mon VPS, sans perte de données.

  • Front React et API Express séparés, authentification JWT
  • Exports PDF générés côté navigateur (jsPDF)
  • Trois conteneurs Docker derrière Nginx Proxy Manager, HTTPS Let’s Encrypt
  • Sauvegardes PostgreSQL et procédure de restauration documentée

React, Express, Prisma, PostgreSQL 17, Docker Compose, VPS Debian
